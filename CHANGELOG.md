# Changelog

All notable changes to RangeSpec are recorded here.

## 0.1.0 — 2026-10-08

- Added the version 0.1 authorization manifest schema.
- Added bounded duplicate-safe JSON input.
- Added schema, semantic, and execution-readiness validation.
- Added normalization, deterministic SHA-256 fingerprints, fail-closed
  redaction, and redacted semantic diffs.
- Added deterministic local advisory review.
- Added an optional Claude structured-output advisory provider.
- Added strict typing, behavioral tests, package-build verification,
  installed-wheel verification, stable example fingerprinting, and pinned CI.
